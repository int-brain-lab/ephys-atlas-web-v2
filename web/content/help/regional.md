## Inspect and select regions {#regional-inspection}

Hover over a brain region to inspect its name and value. In Regions, click a parent to expand or collapse its children; click a leaf to select it. Click a region in a brain view to select only that region. Ctrl-click (Cmd-click on Mac) adds or removes selectable regions. Enable **Select multiple** in Regions to toggle leaves without a modifier.

**Shift-click** a leaf to add the visible sibling range from the most recently selected region. Both endpoints must have the same parent. Repeated Shift-clicks keep the same anchor.

Search highlights matching text and keeps parent and child context. Paths to matches open automatically; other branches stay folded until you expand them. Clearing search restores your previous folding and ordering.

## Read regional values {#regional-values}

The selected statistic determines which regional summary is displayed. Missing values remain explicit rather than being treated as zero.

The miniature colorbar beside a region uses the current feature palette, range and color mapping. Its colored vertical tick marks that region's value against a subdued ramp. Hover for the exact value and any range clipping; the bar is a read-only indicator. In regional mode, faded region names without a colorbar have no value for the selected feature and statistic. In volume mode, region names retain their normal appearance: regional summary values are not defined, and the list provides anatomical navigation and selection.

## Compare selected regions {#regional-comparison}

Global Distribution describes the complete release population. Select regions, then open Compare selected regions to inspect their descriptive statistics and distributions.

**Auto-slice** in Regions moves the three linked slices to an interior position near the selected region’s center. Click the target icon beside the fold/unfold buttons to switch it off and keep slices fixed. Hover or focus the icon for its current state and help. Your choice is included in shared URLs. Manual slice navigation always remains available.
